【Part 2】パフォーマンスレポート自動生成
===============================================

以下のスクリプトで、自動的にパフォーマンスレポートを生成可能：

```csharp
using UnityEngine;
using System.Text;
using System.IO;

public class PerformanceReportGenerator : MonoBehaviour
{
    private BlackHoleParticleManagerAdvanced particleManager;
    
    public void GenerateReport()
    {
        StringBuilder sb = new StringBuilder();
        
        sb.AppendLine("=== Black Hole Particle System Performance Report ===");
        sb.AppendLine($"Generated: {System.DateTime.Now}");
        sb.AppendLine($"GPU: {SystemInfo.graphicsDeviceName}");
        sb.AppendLine($"GPU Memory: {SystemInfo.graphicsMemorySize} MB");
        sb.AppendLine();
        
        // 3モードそれぞれをテスト
        foreach (var mode in new[] { 
            BlackHoleParticleManagerAdvanced.ComputeQuality.Simple,
            BlackHoleParticleManagerAdvanced.ComputeQuality.Standard,
            BlackHoleParticleManagerAdvanced.ComputeQuality.HighPrecision 
        })
        {
            sb.AppendLine($"--- Mode: {mode} ---");
            
            particleManager.SwitchQuality(mode);
            
            // N フレーム実行して平均を計算
            float[] frameTimes = new float[60];
            for (int i = 0; i < 60; i++)
            {
                frameTimes[i] = Time.deltaTime;
            }
            
            float avgTime = System.Array.Average(frameTimes);
            float fps = 1f / avgTime;
            
            sb.AppendLine($"  Avg Frame Time: {avgTime * 1000:F2} ms");
            sb.AppendLine($"  FPS: {fps:F1}");
            sb.AppendLine();
        }
        
        // ファイルに保存
        string reportPath = Path.Combine(Application.persistentDataPath, "perf_report.txt");
        File.WriteAllText(reportPath, sb.ToString());
        
        Debug.Log($"Report saved to: {reportPath}");
    }
}
```

## 物理背景

### Schwarzschild 計量

```
ds² = -(1 - rs/r)c²dt² + (1 - rs/r)⁻¹dr² + r²dΩ²
```

ここで `rs = 2GM/c²` は Schwarzschild 半径。

本実装では以下を採用：
- Newtonian term: `-GM/r²`
- GR correction: `1 / (1 - rs/r)` (metric factor)
- Frame-dragging: 簡略版 Kerr effect (オプション)

### 降着円盤

粒子が以下の条件で消去される：
- `r < rs`: Event Horizon 内
- `distance_to_plane < diskThickness AND r < diskRadius`: 円盤衝突

## 実装メモ

### Warp Divergence 最小化

```hlsl
// ❌ 悪い：分岐で一部スレッドが停止
if ((p.flags & 1u) == 0) return;

// ✓ 良い：条件付き更新（全スレッド実行）
float isAlive = float((p.flags & 1u) != 0);
p.velocity += accel * isAlive;
```

### Thread Group サイズの選択

- NVIDIA: 64 threads (2 warps of 32)
- AMD: 64-128 threads (1 wave)

【Part 7】面接官が注目する点
===============================================

以下の順番で評価されることを想定してください：

1. 「動くのか」（デモの見た目・安定性）
   → 粒子がちゃんと吸い込まれる、クラッシュしない

2. 「速いのか」（パフォーマンス意識）
   → フレームタイムが低い、GPU 占有率が適正

3. 「正しいのか」（物理理解）
   → Schwarzschild 計量について説明できるか
   → Event Horizon の扱いが正確か

4. 「美しいのか」（エンジニアリングセンス）
   → コード整理、設計の洗練度
   → 3 つのバージョンで trade-off を示す

5. 「応用できるのか」（拡張性・応用力）
   → Kerr 計量へどう拡張するか
   → ほかのシミュレーション（N-body など）に応用できるか
